

Python Basics

This repository contains six basic Python programs created as part of the Code with AI / Session 4 and HW-04 activities.

Programs
1. Factorial

factorial.py calculates the factorial of the number 5 using an iterative for loop.

The program initializes the factorial value to 1 and multiplies it by each number from 1 to 5.

2. Fibonacci Series

fibonacci_and_structure.py takes the number of terms as input and generates a Fibonacci series.

The program starts with 0 and 1 and calculates subsequent terms using the previous two values.

3. Student Structure

fibonacci_and_structure.py also contains a Student class.

The class stores:

Name
Roll number
Average marks

The program creates a student named Rahul with roll number 101 and average marks 85.5.

4. Largest Number

largest_number.py takes three numbers as input and determines the largest number using conditional statements.

5. Smallest Number

smallest_number.py compares three predefined numbers and determines the smallest number using conditional statements.

The current values in the program are 15, 7, and 22.

6. Sum of Two Numbers

sum_2_numbers.py takes two numbers as input and calculates their sum.

The inputs are converted to floating-point numbers before addition.

Requirements

These programs use basic Python functionality and do not require external Python packages.

No requirements.txt file is needed for these programs.

How to Run

Make sure Python is installed on your computer.

Run any program from the terminal using:

python filename.py

For example:

python factorial.py

For programs that request input, enter the required values when prompted.
